# زیرساخت به عنوان کد (IaC) و ابزار Terraform

## چیست؟
«زیرساخت به عنوان کد» (Infrastructure as Code یا IaC) به معنای مدیریت و تأمین مراکز داده (شامل سرورها، دیتابیس‌ها و شبکه‌ها) از طریق فایل‌های متنیِ قابل خواندن توسط ماشین است، به جای اینکه یک نفر به صورت دستی سخت‌افزارها را پیکربندی کند یا از رابط‌های کاربری (مثل کلیک کردن در پنل کاربری AWS) استفاده کند.

## چرا مهم است؟
قبل از IaC، اگر شرکتی به یک سرور جدید نیاز داشت، مدیر سیستم (SysAdmin) باید به صورت دستی وارد پنل می‌شد، سیستم‌عامل را نصب می‌کرد، شبکه را تنظیم می‌کرد و دیتابیس را بالا می‌آورد. اگر آن سرور از کار می‌افتاد، او باید دقیقاً به خاطر می‌آورد که چه کارهایی انجام داده تا بتواند دوباره آن را بسازد.

با IaC، زیرساخت شما درست مانند برنامه شما، به صورت کد نوشته می‌شود. این کار چند مشکل بزرگ را حل می‌کند:
۱. **اتوماسیون و سرعت**: می‌توانید یک محیط ابری کامل و پیچیده را تنها با یک دستور و در عرض چند دقیقه راه‌اندازی کنید.
۲. **سازگاری و جلوگیری از انحراف (Drift)**: مشکل "روی سیستم من کار می‌کرد" را در سطح زیرساخت از بین می‌برد. تمام محیط‌ها (Dev، Staging، Prod) دقیقاً مشابه هم خواهند بود.
۳. **کنترل نسخه (Version Control)**: چون زیرساخت حالا فقط مجموعه‌ای از فایل‌های متنی است، می‌تواند در گیت (Git) کامیت شود. شما می‌توانید تغییرات سرورها را از طریق Pull Request بررسی کنید و اگر چیزی خراب شد، به نسخه قبلی (Rollback) بازگردید.

## ابزارهای کلیدی
- **ترافورم (Terraform)**: محبوب‌ترین ابزار مستقل از فضای ابری (Cloud-agnostic) برای IaC است. با آن می‌توانید منابع را در AWS، Google Cloud، Azure و حتی گیت‌هاب ایجاد کنید.
- **Ansible / Chef / Puppet**: عمدتاً ابزارهای مدیریت پیکربندی (Configuration Management) هستند (برای تنظیم نرم‌افزارهای *داخل* سرور پس از ساخته شدن سرور استفاده می‌شوند).
- **AWS CloudFormation**: ابزار اختصاصی خود آمازون برای IaC.

## مثال (ترافورم - زبان HCL)
در اینجا نحوه ایجاد یک سرور ساده AWS EC2 با استفاده از زبان پیکربندی HCL در ترافورم آمده است:

```hcl
# ۱. تعریف ارائه‌دهنده خدمات ابری
provider "aws" {
  region = "us-west-2"
}

# ۲. تعریف منبعی که می‌خواهید ایجاد کنید
resource "aws_instance" "my_web_server" {
  ami           = "ami-0c55b159cbfafe1f0" # ایمیج سیستم‌عامل اوبونتو
  instance_type = "t2.micro"              # اندازه و قدرت سرور

  tags = {
    Name = "HelloWorldServer"
  }
}
```
وقتی دستور `terraform apply` را اجرا می‌کنید، ترافورم با API سرویس AWS ارتباط برقرار کرده و دقیقاً همین سرور را برای شما می‌سازد.
