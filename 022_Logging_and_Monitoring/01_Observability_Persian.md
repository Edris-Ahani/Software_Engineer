# لاگین، مانیتورینگ و رویت‌پذیری (Observability)

## چیست؟
هنگامی که برنامه بک‌اند شما در محیط پروداکشن در حال اجراست، شما عملاً کور هستید مگر اینکه راهی برای دیدن آنچه برنامه انجام می‌دهد داشته باشید. **رویت‌پذیری (Observability)** توانایی اندازه‌گیری وضعیت‌های داخلی یک سیستم از طریق بررسی خروجی‌های آن است. این مفهوم از سه ستون اصلی تشکیل شده است:
۱. **لاگ‌ها (Logs)**: سوابق غیرقابل تغییر از رویدادهای مجزایی که در طول زمان اتفاق افتاده‌اند (مثلاً "کاربر X در ساعت 10:05 شب وارد شد").
۲. **متریک‌ها (Metrics)**: اعداد و ارقامی که در بازه‌های زمانی اندازه‌گیری می‌شوند (مانند درصد مصرف CPU، میزان مصرف رم، تعداد خطاهای HTTP 500 در هر دقیقه).
۳. **ردیابی (Traces)**: نمایشی از سفر یا درخواست یک کاربر واحد در حین عبور از یک سیستم توزیع‌شده (برای مایکروسرویس‌ها کاملاً ضروری است).

## چه مشکلاتی را حل می‌کند؟
- **دیباگ کردن مشکلات پروداکشن**: وقتی کاربری یک باگ را گزارش می‌دهد، لاگ‌ها به شما اجازه می‌دهند دقیقاً ببینید چه اتفاقی رخ داده که منجر به آن خطا شده است.
- **هشداردهی پیشگیرانه (Proactive Alerting)**: ابزارهای مانیتورینگ می‌توانند *قبل از* کرش کردن سیستم، یک پیام در Slack یا یک پیامک برای مهندس شیفت ارسال کنند (مثلاً وقتی مصرف CPU به ۹۰ درصد می‌رسد).
- **بهینه‌سازی پرفورمنس**: ابزارهای ردیابی (Traces) به شما کمک می‌کنند دقیقاً تشخیص دهید کدام کوئری دیتابیس یا کدام مایکروسرویس باعث کندی پاسخ API شده است.

## ابزارهای محبوب در صنعت
- **لاگین**: ELK Stack (ترکیب Elasticsearch, Logstash, Kibana)، Datadog، Splunk.
- **مانیتورینگ و متریک‌ها**: Prometheus (برای جمع‌آوری متریک‌ها) و Grafana (برای مصورسازی و ساخت داشبورد).
- **ردیابی**: Jaeger، Zipkin، OpenTelemetry.

## مثال‌ها

### لاگین خوب در برابر بد (Node.js)
```javascript
// BAD LOGGING (Hard to search, missing context)
console.log("Error occurred!");
console.log(err.message);

// GOOD LOGGING (Structured JSON logging using a library like Winston or Pino)
// Structured logs are easily searchable in tools like Kibana.
logger.error({
    message: "Failed to process payment",
    userId: 12345,
    orderId: "ORD-999",
    errorMessage: err.message,
    stackTrace: err.stack,
    timestamp: new Date().toISOString()
});
```
