# تابلوی کار ماندگار

[English](README_English.md) · [دوره](../../README_Persian.md) · [اجرای کامل](../../RUNNING_Persian.md)

## هدف و پیش‌نیاز

گذار خالص کار، تغییر بدون mutation، متن نامطمئن امن، ذخیرهٔ نسخه‌دار، بازیابی شکست و بازگردانی focus.

پیش‌نیاز: HTML، CSS، DOM و Node نسخهٔ ۲۴ یا جدیدتر برای سرور محلی. وابستگی npm ندارد.

## اجرا و ورودی

از ریشهٔ دوره اجرا کنید:

```bat
cmd /c node scripts/serve.mjs --duration=600
```

سپس http://127.0.0.1:4173/projects/002_persistent_board/index.html را باز کنید. ورودی از فرم داخل صفحه گرفته می‌شود و دادهٔ اولیه به شبکهٔ بیرونی وابسته نیست. سرور پس از ۶۰۰ ثانیه بسته می‌شود.

## خروجی و معیار پذیرش

عنوان اضافه و تکمیل کنید و reload بزنید؛ یک کار تکمیل‌شده می‌بینید. حذف، focus را به ورودی برمی‌گرداند. JSON خراب، حالت حافظه‌ای می‌دهد و تا reset مقدار قبلی را حفظ می‌کند.

با Tab و Enter همان کار را انجام دهید. در عرض باریک محتوای ضروری نباید از دست برود. متن شبیه HTML باید لفظی نمایش داده شود و کد اجرا نکند.

## بررسی

```bat
cmd /c node --test tests/core.test.mjs tests/server.test.mjs
cmd /c node scripts/check.mjs
```

پس از نصب ابزار اختیاری و ساخت React، cmd /c npm run e2e را از ریشه اجرا کنید. تست مرورگر همین مسیرهای قابل مشاهده را بررسی می‌کند. نصب، نتیجهٔ واقعی و محدودیت در [گزارش](../../VALIDATION_Persian.md) آمده است.

## محدودیت و تمرین تکمیلی

فقط دادهٔ محلی تک‌کاربره با حداکثر ۱۰۰۰ کار و ۱۲۰ نویسه برای عنوان است. حل تعارض تب، backend و پشتیبان ندارد. آداپتور IndexedDB و سیاست تعارض اضافه کنید.

ابتدا معیار پذیرش و حالت شکست توسعهٔ انتخابی را بنویسید. منطق دامنه در lib و جزئیات UI در همین پروژه باقی بماند؛ همهٔ مثال‌ها محلی و آموزشی‌اند.
