# آموزش مهندسی فرانت‌اند؛ از پایه تا مهارت‌های سطح ارشد

[English](README_English.md) · [انتخاب زبان](README.md)

این مجموعه ۶۴ فصل شماره‌دار دارد. هر فصل نسخهٔ کامل فارسی و انگلیسی، توضیح سازوکار، خطای رایج، تمرین با معیار پذیرش، راهنمای حل و منبع رسمی دارد. از وب و HTML شروع می‌کنیم و به معماری، طراحی سیستم و تحویل محصول می‌رسیم. هدف ساخت دانش عملی است؛ ارشد شدن علاوه بر مطالعه به تجربهٔ محصول، قضاوت فنی و همکاری نیاز دارد.

## پیش‌نیاز و شروع

برای شروع تجربهٔ برنامه‌نویسی لازم نیست؛ کار معمول با رایانه و فایل کافی است. ابتدا فصل 001 و 002 را بخوانید. مثال‌های اصلی فقط Node نسخهٔ ۲۴ یا جدیدتر و مرورگر به‌روز می‌خواهند و نصب npm ندارند. React و تست مرورگر نصب مستقل و اختیاری دارند. همهٔ کدها، داده، تست و راهنما در همین موضوع قرار دارد.

[راهنمای اجرا و نصب](RUNNING_Persian.md) · [راهنمای نمونه‌ها](examples/README_Persian.md) · [گزارش اعتبارسنجی](VALIDATION_Persian.md)

## مسیر مرحله‌ای

1. فصل‌های 001 تا 015: وب، محیط، Git، HTTP، درون مرورگر، HTML، فرم، دسترس‌پذیری و CSS.
2. فصل‌های 016 تا 028: JavaScript، الگوریتم، ناهمگامی، DOM، API، ذخیره، مسیریابی، TypeScript و ابزار.
3. فصل‌های 029 تا 039: اشکال‌زدایی، تست، React، مالکیت داده، مسیریابی، روش رندر و انتخاب فریم‌ورک.
4. فصل‌های 040 تا 049: امنیت، هویت، کارایی، کش، worker، آفلاین، ارتباط زنده، دسترس‌پذیری، بومی‌سازی و SEO.
5. فصل‌های 050 تا 058: سیستم طراحی، معماری، طراحی سیستم، دادهٔ بزرگ، گرافیک، تحویل، مشاهده‌پذیری، وابستگی و همکاری.
6. فصل‌های 059 تا 064: سه پروژه، ارزیابی، عیب‌یابی و ادامهٔ یادگیری.

پس از HTML و CSS پروژهٔ اول را شروع کنید؛ پس از DOM و ذخیره پروژهٔ دوم و پس از React و تست پروژهٔ سوم را انجام دهید. می‌توانید فصل پروژه‌ها را زودتر باز کنید و پس از بخش‌های پیشرفته به آن‌ها برگردید.

برای هر فصل ابتدا خروجی را پیش‌بینی کنید، کد را اجرا کنید، یک حالت مرزی اضافه کنید و بدون نگاه به راهنما تمرین را حل کنید. با چک‌لیست فصل 062 ارزیابی کنید. برنامهٔ پیشنهادی ۱۶ هفته است: ۴ هفته مبانی، ۴ هفته JavaScript و TypeScript، ۳ هفته React و تست، ۳ هفته مهندسی پیشرفته و ۲ هفته پروژه و بازبینی؛ زمان واقعی به تمرین و تجربه وابسته است.

## پروژه‌ها و مرز پوشش

- [001 — کاتالوگ دسترس‌پذیر](projects/001_accessible_catalog/README_Persian.md): HTML، CSS، جست‌وجو و تاریخچهٔ URL.
- [002 — تابلوی کار](projects/002_persistent_board/README_Persian.md): reducer خالص، اعتبارسنجی، ذخیره و بازیابی شکست.
- [003 — داشبورد React](projects/003_react_dashboard/README_Persian.md): TypeScript، state، فیلتر و ساخت production.

هستهٔ دوره مستقل از فریم‌ورک است؛ React مسیر عملی اصلی و Vue، Angular، Svelte و Web Component فصل مقایسه‌ای دارند. SSR، Next.js، RSC، microfrontend، GraphQL، WebRTC و WebAssembly با سازوکار، tradeoff و تمرین طراحی معرفی می‌شوند و آزمایشگاه تولیدی مستقل برای همهٔ آن‌ها وجود ندارد. پروژه‌ها آموزشی و محلی هستند؛ backend واقعی، پرداخت یا احراز هویت production پیاده نشده است.

برای ادامه از [MDN](https://developer.mozilla.org/en-US/docs/Learn_web_development)، [React](https://react.dev/learn)، [TypeScript](https://www.typescriptlang.org/docs/handbook/intro.html) و [WAI](https://www.w3.org/WAI/tutorials/) و منبع اختصاصی هر فصل استفاده کنید. راهنمای نصب و ابزار با مستند رسمی بررسی شده و نسخه‌های بسته‌ها در manifest و lockfile مستقل ثبت می‌شود.
