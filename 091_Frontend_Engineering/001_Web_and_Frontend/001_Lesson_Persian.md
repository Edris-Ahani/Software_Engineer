# 001 — وب و نقش مهندس فرانت‌اند

[English](./001_Lesson_English.md) · [مسیر دوره](../README_Persian.md) · [راهنمای اجرا](../RUNNING_Persian.md)

## مفهوم و سازوکار

وب مجموعه‌ای از سندها و دارایی‌ها با نشانی URL است. مرورگر آن‌ها را دریافت می‌کند؛ HTML ساختار، CSS ظاهر و JavaScript رفتار را مشخص می‌کند. عملیات قابل اعتماد مانند مجوز پرداخت بر عهدهٔ سرور است. کاربر کنترل کلاینت را دارد؛ پنهان کردن دکمه هرگز مجوز دسترسی را اعمال نمی‌کند.

در بهبود تدریجی ابتدا HTML مفید می‌سازیم، سپس ظاهر و تعامل اضافه می‌کنیم. رندر سمت کلاینت برای تعاملات پیچیده مناسب است، اما هزینهٔ دانلود، تجزیه و اجرای کد دارد. مهندس ارشد پیش از انتخاب فریم‌ورک، کاربران، محدودیت دستگاه و حالت‌های شکست را مشخص می‌کند.

## خطاهای رایج

فرانت‌اند را با React یکسان ندانید و لپ‌تاپ سریع خود را نمایندهٔ همهٔ کاربران فرض نکنید.

## تمرین و معیار پذیرش

مسئولیت‌های پرداخت را میان مرورگر، API، پایگاه داده و ارائه‌دهندهٔ پرداخت تقسیم کنید. رفتار قطع شبکه یا JavaScript را بنویسید.

## راهنمای حل

مرورگر ورودی و وضعیت را نمایش می‌دهد؛ سرور قیمت، موجودی، هویت و تکرارناپذیری عملیات را بررسی می‌کند. صفحهٔ خطای خوانا و مسیر تلاش مجدد امن داشته باشید.
