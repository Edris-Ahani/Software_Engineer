# 013 — واکنش‌گرایی و پرس‌وجوی ظرف

[English](./013_Lesson_English.md) · [مسیر دوره](../README_Persian.md) · [راهنمای اجرا](../RUNNING_Persian.md)

## مفهوم و سازوکار

طراحی واکنش‌گرا با فضای موجود، روش ورودی، بزرگ‌نمایی متن و محتوا سازگار می‌شود. با طرح باریک مفید شروع کنید و وقتی محتوا لازم دارد پیچیدگی را افزایش دهید. فهرست دستگاه، راهبرد breakpoint نیست؛ ترجمهٔ طولانی و پنجرهٔ تقسیم‌شده هم فضای موجود را عوض می‌کنند.

media query به viewport یا محیط و container query به ظرف خود کامپوننت پاسخ می‌دهد؛ containment را آگاهانه تعریف و پشتیبانی همان قابلیت را بررسی کنید. با clamp اندازهٔ سیال و حداقل خوانا بسازید. هدف لمسی، حالت افقی، کاهش حرکت، zoom و محتوای واقعی را آزمایش کنید. feature query و مسیر جایگزین مانع حذف دسترسی ضروری در مرورگر قدیمی می‌شوند.

## خطاهای رایج

بزرگ‌نمایی لمسی را غیرفعال نکنید. تصویر واکنش‌گرا ثابت نمی‌کند کنترل با صفحه‌کلید یا متن بزرگ قابل استفاده است.

## تمرین و معیار پذیرش

یک کارت محصول را در sidebar و محتوای اصلی قرار دهید. بدون تکرار وابسته به viewport، طرح را با عرض ظرف تطبیق دهید.

## راهنمای حل

روی پوشاننده container-type بگذارید و inline size آن را پرس‌وجو کنید. پیش از query مسیر جایگزین تک‌ستونی داشته باشید.
