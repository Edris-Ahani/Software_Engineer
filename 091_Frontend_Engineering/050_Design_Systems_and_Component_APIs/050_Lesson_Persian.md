# 050 — سیستم طراحی و API کامپوننت

[English](./050_Lesson_English.md) · [مسیر دوره](../README_Persian.md) · [راهنمای اجرا](../RUNNING_Persian.md)

## مفهوم و سازوکار

سیستم طراحی ترکیب توکن، کامپوننت، راهنمای استفاده و حاکمیت است. توکن نیت مانند سطح، خطر و فاصله را بیان و کامپوننت تعامل و حالت دسترس‌پذیر را پیاده می‌کند. API باید انتخاب معتبر را توصیف کند، نه همهٔ سبک داخلی را با prop بیرون بدهد.

حالت عادی، hover، focus، غیرفعال، انتظار، خطا، متن بلند، RTL و واکنش‌گرا را مستند کنید. برای تنوع معنادار ترکیب و برای تصمیم پایدار طراحی variant صریح داشته باشید. ابزار نمایش مستقل مانند Storybook حالت را قابل بازبینی می‌کند و جای تست یکپارچهٔ برنامه نیست. API عمومی را نسخه‌بندی، راهنمای مهاجرت و مالک مشخص کنید تا سیستم قابل تکامل باشد.

## خطاهای رایج

کامپوننت عمومی با ده‌ها prop بولی ترکیب متناقض می‌سازد. یکدستی دیداری معناشناسی صحیح را تضمین نمی‌کند.

## تمرین و معیار پذیرش

API دکمه با variant، loading، نام دسترس‌پذیر و ویژگی بومی طراحی کنید؛ زمان استفاده از کامپوننت لینک را توضیح دهید.

## راهنمای حل

union کوچک variant، معنای بومی و بازخورد انتظار داشته باشید و ناوبری را anchor واقعی نگه دارید.
