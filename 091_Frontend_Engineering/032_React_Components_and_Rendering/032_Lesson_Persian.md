# 032 — کامپوننت و رندر در React

[English](./032_Lesson_English.md) · [مسیر دوره](../README_Persian.md) · [راهنمای اجرا](../RUNNING_Persian.md)

## مفهوم و سازوکار

کامپوننت React تابعی است که UI را براساس props و state توصیف می‌کند. JSX بیان این توصیف است و رشتهٔ HTML نیست. render باید خالص باشد؛ در render معمولی کلاینت وضعیت بیرونی را تغییر ندهید، subscribe یا fetch نکنید. React ممکن است پیش از commit دوباره render کند.

props از والد به فرزند می‌رود و رخداد درخواست تغییر را به بالا منتقل می‌کند. ترکیب با children یا کامپوننت متمرکز از شیء تنظیمات عظیم جلوگیری می‌کند. key پایدار هویت فرزندان را هنگام درج و جابه‌جایی حفظ می‌کند؛ index وقتی هویت آیتم جابه‌جا می‌شود ناامن است. state به موقعیت و هویت درخت وابسته است و تغییر key می‌تواند عمداً آن را reset کند.

## خطاهای رایج

کامپوننت را مانند تابع عادی صدا نزنید و وقتی هویت پایدار لازم است نوع کامپوننت را داخل کامپوننت دیگر تعریف نکنید.

## تمرین و معیار پذیرش

داشبورد React را به فرم فیلتر، فهرست کار و وضعیت با props دارای نوع صریح تقسیم کنید.

## راهنمای حل

مالک مجموعه در یک والد باشد، مقدار و callback عبور دهید و id کار را key کنید؛ حفظ هویت هنگام جابه‌جایی را بسنجید.
