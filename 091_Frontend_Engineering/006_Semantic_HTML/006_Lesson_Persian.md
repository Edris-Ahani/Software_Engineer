# 006 — HTML معنایی

[English](./006_Lesson_English.md) · [مسیر دوره](../README_Persian.md) · [راهنمای اجرا](../RUNNING_Persian.md)

## مفهوم و سازوکار

HTML پیش از ظاهر، معنا را توصیف می‌کند. main برای محتوای اصلی، nav برای ناوبری، article برای محتوای مستقل و سلسله‌مراتب عنوان برای ساختار سند است. لینک مکان را تغییر می‌دهد و دکمه عملی را انجام می‌دهد. کنترل بومی رفتار صفحه‌کلید و معنای دسترس‌پذیر دارد که div کلیک‌پذیر فاقد آن است.

ویژگی‌ها وظیفهٔ متفاوت دارند: id یک عنصر را مشخص می‌کند، class قلاب سبک‌دهی گروهی است و data-* فرادادهٔ برنامه را نگه می‌دارد. متن نامطمئن را با textContent یا درج متنی فریم‌ورک نمایش دهید. سند معتبر شامل doctype، lang، charset، title و viewport بسازید. HTML معنایی، تست با نقش دسترس‌پذیر و استفاده در نبود CSS را هم بهتر می‌کند.

## خطاهای رایج

عنوان را به‌خاطر اندازهٔ پیش‌فرض انتخاب نکنید، کنترل‌های تعاملی را تودرتو نگذارید و دکمه را با div جایگزین نکنید.

## تمرین و معیار پذیرش

یک article محصول با عنوان، قیمت، لینک جزئیات و دکمهٔ افزودن بسازید. فقط با Tab، Shift+Tab و Enter حرکت کنید.

## راهنمای حل

لینک href واقعی و دکمه type="button" دارد. صفحه یک main اصلی و عنوان‌های با ترتیب منطقی دارد.
