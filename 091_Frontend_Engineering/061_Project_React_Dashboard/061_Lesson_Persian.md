# 061 — پروژهٔ سوم: داشبورد React و TypeScript

[English](./061_Lesson_English.md) · [مسیر دوره](../README_Persian.md) · [راهنمای اجرا](../RUNNING_Persian.md)

## مفهوم و سازوکار

پروژهٔ React جریان کار را با کامپوننت دارای نوع، reducer، فیلتر مشتق و ساخت production بازسازی می‌کند. همان قرارداد دامنه را استفاده کنید و صرف ورود فریم‌ورک قانون کسب‌وکار را تغییر ندهید. مرجع دادهٔ محلی دارد و استقرار و اعتبارنامه را وارد مرورگر نمی‌کند.

برای خروجی سطح ارشد مرحله‌ای توسعه دهید: آداپتور API معتبر، کش با کلید وابسته به کاربر، فیلتر URL، به‌روزرسانی خوش‌بینانه با تطبیق، بازیابی خطای دسترس‌پذیر و telemetry پاک‌سازی‌شده. این توسعه‌ها تکلیف طراحی‌اند و قابلیت ادعاشدهٔ مرجع نیستند. تست درستی و بررسی نوع را از بسته‌بندی مستقل نگه دارید.

## خطاهای رایج

پیش از روشن شدن مسئولیت هر ابزار، store عمومی، کتابخانهٔ query، router و چارچوب کامپوننت را هم‌زمان اضافه نکنید.

## تمرین و معیار پذیرش

وابستگی مستقل پروژه را نصب، typecheck و build را اجرا و dist ارائه‌شده را ببینید؛ مهاجرت API با حالت شکست پیشنهاد دهید.

## راهنمای حل

reducer خالص و دارای نوع بماند، اعتبارسنجی بیرونی در مرز آداپتور و پیش از رفتار خوش‌بینانه یک مالک داده مشخص شود.
