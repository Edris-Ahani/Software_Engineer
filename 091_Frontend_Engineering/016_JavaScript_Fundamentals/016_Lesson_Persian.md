# 016 — مبانی جاوااسکریپت

## مفهوم و سازوکار

مقدارهای JavaScript شامل undefined، null، boolean، number، bigint، string، symbol و object هستند. const تغییر اتصال متغیر را منع می‌کند و شیء را منجمد نمی‌کند. در مرز ورودی تبدیل صریح انجام دهید؛ Number("") صفر و Number("abc") برابر NaN است. پیش از محاسبه روی ورودی کاربر، Number.isFinite و محدودیت دامنه را بررسی کنید.

truthiness و تفاوت || با ?? را بفهمید؛ دومی فقط برای null یا undefined مقدار جایگزین می‌دهد و صفر و رشتهٔ خالی را حفظ می‌کند. برابری سخت‌گیرانه را پیش‌فرض بگیرید. ممیز شناور هر اعشار را دقیق نمایش نمی‌دهد؛ اگر مدل ارز اجازه می‌دهد پول را با واحد خرد صحیح و معتبر ذخیره کنید. شرط و حلقه ابتدا باید قانون کسب‌وکار را روشن بیان کند.

## خطاهای رایج

وقتی صفر معتبر است شرط falsy به کار نبرید و با parseInt بخش اعشاری پول را بی‌صدا حذف نکنید.

## تمرین و معیار پذیرش

مجموع سبد را از قیمت و تعداد صحیح محاسبه کنید. مقدار منفی، اعشاری، نامتناهی و عدد صحیح ناامن را رد کنید.

## راهنمای حل

هر قلم را پیش از جمع و محدودهٔ مجموع نهایی را اعتبارسنجی کنید. قالب نمایش را از محاسبه جدا نگه دارید.
