# 033 — وضعیت و reducer در React

[English](./033_Lesson_English.md) · [مسیر دوره](../README_Persian.md) · [راهنمای اجرا](../RUNNING_Persian.md)

## مفهوم و سازوکار

state تصویر یک render است. تغییر آن render دیگری درخواست می‌کند و مقدار گرفته‌شده در handler جاری را بازنویسی نمی‌کند. وقتی مقدار بعدی به قبلی وابسته است از به‌روزرسانی تابعی استفاده کنید. React می‌تواند تغییرات را batch کند؛ چند setter با مقدار یکسان گرفته‌شده ممکن است یک نتیجه بدهند.

حداقل منبع حقیقت را ذخیره و شمارنده و فهرست فیلترشده را هنگام render استخراج کنید. state را به نزدیک‌ترین مالک مشترک ببرید و میان فرزندان تکرار نکنید. reducer گذارهای مرتبط را متمرکز و invariant را قابل تست می‌کند. Context مقدار را در زیردرخت توزیع می‌کند و خودبه‌خود store انتخابی با کارایی بالا نیست.

## خطاهای رایج

تغییر آرایه و بازگرداندن همان مرجع ممکن است تغییر را پنهان کند. state مشتق‌شدهٔ جدا می‌تواند از اصل فاصله بگیرد.

## تمرین و معیار پذیرش

عمل add و toggle را با reducer خالص بسازید؛ عنوان خالی و id تکراری را رد و شمارندهٔ تکمیل را استخراج کنید.

## راهنمای حل

پیش از ساخت آرایهٔ جدید اعتبارسنجی کنید، فقط آیتم تغییرکرده را کپی کنید و اجازه ندهید عمل نامعتبر state قبلی را عوض کند.
