# 026 — مبانی تایپ‌اسکریپت

[English](./026_Lesson_English.md) · [مسیر دوره](../README_Persian.md) · [راهنمای اجرا](../RUNNING_Persian.md)

## مفهوم و سازوکار

TypeScript پیش از اجرا مدلی از JavaScript را بررسی می‌کند؛ نوع‌ها حذف می‌شوند و دادهٔ شبکه را اعتبارسنجی نمی‌کنند. strict را فعال، مقدار اختیاری را صریح مدل و وقتی خواناست از استنتاج استفاده کنید. unknown پیش از مصرف بررسی می‌خواهد؛ any بررسی مفید را خاموش و فرض بدون کنترل را منتشر می‌کند.

برای رکورد از نوع شیء، برای انتخاب‌ها از union و برای ماشین حالت از discriminant استفاده کنید. حالت مانند { status: "success", data } نمایش ترکیب ناممکن را دشوار می‌کند. Readonly قرارداد زمان کامپایل است و شیء زمان اجرا را منجمد نمی‌کند. type assertion به کامپایلر می‌گوید اعتماد کند و تبدیل یا اعتبارسنجی انجام نمی‌دهد.

## خطاهای رایج

non-null assertion می‌تواند هشدار کامپایلر را به شکست زمان اجرا تبدیل کند. حذف نوع، کد را اجرا می‌کند ولی type check نیست.

## تمرین و معیار پذیرش

حالت بیکار، بارگیری، موفق و خطا را بدون data و error اختیاری روی همهٔ حالت‌ها مدل کنید و همه را پوشش دهید.

## راهنمای حل

union متمایزشده و بررسی جامع با never بسازید. ورودی API را پیش از ساخت حالت موفق اعتبارسنجی کنید.
