# 060 — پروژهٔ دوم: تابلوی کار ماندگار

[English](./060_Lesson_English.md) · [مسیر دوره](../README_Persian.md) · [راهنمای اجرا](../RUNNING_Persian.md)

## مفهوم و سازوکار

تابلوی کار قانون دامنه و ذخیره را به رابط کوچک اضافه می‌کند. reducer خالص add، toggle و remove را مدیریت می‌کند. رکورد ذخیره‌شده نسخهٔ schema دارد و پیش از ورود به state بررسی می‌شود. شکست ذخیره باید رابط حافظه‌ای قابل استفاده و وضعیت صادقانه باقی بگذارد.

ابتدا اعتبارسنجی و تست مرزی، سپس ارسال فرم، عمل فهرست، بازگردانی focus و ذخیره را وصل کنید. عنوان متن نامطمئن و id پایدار است. مرجع تک‌کاربره و محلی است؛ همگام‌سازی سرور، هویت، حل تعارض تب و پشتیبان ماندگار ندارد.

## خطاهای رایج

دادهٔ ذخیره‌شدهٔ خراب را بی‌صدا پاک و فوراً بازنویسی نکنید. بازیابی را توضیح و reset آگاهانه بخواهید.

## تمرین و معیار پذیرش

کار اضافه، تکمیل، حذف و reload کنید؛ schema را خراب و شکست نوشتن را شبیه‌سازی کنید و ادامهٔ کار را بسنجید.

## راهنمای حل

load/save محافظت‌شده، کنترل reset قابل مشاهده و گذار تغییرناپذیر داشته باشید؛ دادهٔ خراب تا reset صریح حفظ شود.
