## Concept and mechanism

DOM is the document tree; CSSOM represents style information; an origin is scheme, host, and port. A task schedules JavaScript work, a microtask follows the current stack, and a worker executes in a separate context. Hydration connects client behavior to server markup; reconciliation matches UI descriptions to existing identities.

A cache hit reuses a representation; invalidation marks it unsuitable for reuse. Idempotency means repeating an operation has the same intended effect as one execution. A race depends on timing; backpressure prevents a producer from overwhelming a consumer. An invariant is a rule that must hold across state transitions. Observability provides evidence about system behavior from outputs.

Continue by maintaining a real product: write an ADR, improve one measured bottleneck, audit an accessible workflow, update dependencies, and lead a release. Specialized areas such as WebGL, complex editors, mapping, advanced framework internals, and native mobile require additional study beyond this core curriculum.

## Common mistakes

Do not treat a glossary definition as practical mastery. APIs and framework defaults change, so verify current official documentation before production changes.

## Exercise and acceptance criteria

Explain ten glossary terms using failures from the supplied projects, then choose one specialization and write a learning plan with observable outcomes.

## Solution guidance

Pair each term with a reproduction and fix. Choose outcomes such as a measured improvement or accessible interaction rather than a list of videos watched.
