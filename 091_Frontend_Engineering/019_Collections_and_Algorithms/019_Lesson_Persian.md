# 019 — مجموعه‌ها و الگوریتم‌های کاربردی

[English](./019_Lesson_English.md) · [مسیر دوره](../README_Persian.md) · [راهنمای اجرا](../RUNNING_Persian.md)

## مفهوم و سازوکار

ساختار داده را براساس عملیات انتخاب کنید. Array پیمایش مرتب، Set یکتایی و Map جست‌وجوی کلیدی را فراهم می‌کند. فیلتر n ردیف O(n)، مرتب‌سازی معمولاً O(n log n) و جست‌وجوی آرایهٔ دوم در حلقه ممکن است O(n*m) باشد. ایندکس بر اساس id اغلب این اسکن تودرتو را با هزینهٔ حافظه حذف می‌کند.

متدهای آرایه از نظر تغییر متفاوت‌اند؛ sort و reverse تغییر می‌دهند و toSorted و toReversed در محیط پشتیبانی‌شده کپی می‌سازند. شناسهٔ پایدار از موقعیت برای انتخاب و key کامپوننت مطمئن‌تر است. برای مجموعهٔ بزرگ، صفحه‌بندی سرور و وضعیت محدود کلاینت را ترکیب کنید؛ virtualization تعداد DOM را کم می‌کند و حجم دانلود را کاهش نمی‌دهد.

## خطاهای رایج

هنگام رندر هزاران گره غیرضروری، حلقهٔ کوچک را اولویت ندهید. پیچیدگی Map به پیاده‌سازی وابسته است و دسترسی میانگین زیرخطی لازم دارد.

## تمرین و معیار پذیرش

محصول را بدون find داخل map به نام دسته متصل کنید؛ دستهٔ ناشناخته و شناسهٔ تکراری را صریح مدیریت کنید.

## راهنمای حل

Map دسته‌ها را یک بار بسازید و محصول‌ها را یک بار پیمایش کنید؛ برچسب جایگزین و سیاست رد شناسهٔ تکراری مشخص کنید.
