# 024 — ذخیره‌سازی و IndexedDB

[English](./024_Lesson_English.md) · [مسیر دوره](../README_Persian.md) · [راهنمای اجرا](../RUNNING_Persian.md)

## مفهوم و سازوکار

وضعیت موقتی تعامل را در حافظه نگه دارید. sessionStorage به نشست صفحه محدود و localStorage برای هر origin ماندگار و همگام است. IndexedDB دادهٔ ساخت‌یافته را غیرهمگام با ایندکس و تراکنش ذخیره می‌کند و برای دادهٔ بزرگ آفلاین مناسب است. cookie طبق محدوده و ویژگی خود همراه HTTP می‌رود.

همهٔ ذخیره‌سازی مرورگر ممکن است به علت سهمیه، تنظیم حریم خصوصی، حذف کاربر یا دادهٔ قدیمی خراب شکست بخورد. schema را نسخه‌بندی، هنگام خواندن اعتبارسنجی و بازیابی را بدون نابودی پنهانی کار کاربر فراهم کنید. وضعیت محلی مرجع مجوز یا پرداخت نیست. cookie دارای HttpOnly برای JavaScript قابل خواندن نیست؛ localStorage را هر اسکریپت اجراشده در همان origin می‌خواند.

## خطاهای رایج

ذخیرهٔ token در localStorage را سیاست پیش‌فرض نگیرید و شکست‌ناپذیری JSON.parse را فرض نکنید. ذخیرهٔ مرورگر نسخهٔ پشتیبان نیست.

## تمرین و معیار پذیرش

فهرست کار کوچک را با نسخهٔ schema ذخیره کنید؛ JSON را خراب و ادامهٔ استفاده همراه توضیح بازیابی را بررسی کنید.

## راهنمای حل

خطای خواندن و نوشتن را بگیرید، رکورد را اعتبارسنجی و وضعیت مفید را حفظ کنید؛ مسیر حافظه‌ای داشته باشید و برای نوشتن پرهزینه به IndexedDB بروید.
