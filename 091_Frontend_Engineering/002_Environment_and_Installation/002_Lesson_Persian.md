# 002 — نصب ابزار و محیط کار

[English](./002_Lesson_English.md) · [مسیر دوره](../README_Persian.md) · [راهنمای اجرا](../RUNNING_Persian.md)

## مفهوم و سازوکار

یک نسخهٔ پشتیبانی‌شدهٔ LTS از Node.js را از صفحهٔ رسمی دریافت کنید. در Windows بستهٔ MSI مناسب معماری را نصب کنید، npm و PATH را فعال نگه دارید، Command Prompt را دوباره باز کنید و فرمان‌های نسخه را اجرا کنید. در macOS از بستهٔ رسمی و در Linux از باینری رسمی یا مدیر نسخهٔ معرفی‌شده توسط Node استفاده کنید. WSL فایل‌سیستم، نصب Node و بسته‌های مستقل دارد؛ node_modules را با Windows مشترک نکنید.

یک ویرایشگر و مرورگر به‌روز دارای DevTools نصب کنید. آزمایش‌های اصلی وابستگی npm ندارند و Node نسخهٔ ۲۴ یا جدیدتر می‌خواهند. پروژهٔ اختیاری React وابستگی و lockfile خودش را دارد؛ نصب را فقط در همان پروژه انجام دهید. برای نصب روزمرهٔ بسته‌ها دسترسی مدیر لازم نیست. Node ابزار این آموزش است و موتور JavaScript مرورگر محسوب نمی‌شود.

## خطاهای رایج

اگر node پیدا نشد، ترمینال را دوباره باز و PATH را بررسی کنید. اسکریپت نصب ناشناس را با دسترسی مدیر اجرا نکنید.

## تمرین و معیار پذیرش

از ریشهٔ دوره، cmd /c node --version و cmd /c npm --version و سپس cmd /c node scripts/check.mjs را اجرا کنید.

## راهنمای حل

فرمان‌های نسخه شمارهٔ نصب‌شده را نشان می‌دهند؛ check.mjs نتیجهٔ بررسی مستندات و نحو را گزارش می‌کند. در Linux و macOS پیشوند cmd /c را حذف کنید.
