# 063 — عیب‌یابی و سازگاری

[English](./063_Lesson_English.md) · [مسیر دوره](../README_Persian.md) · [راهنمای اجرا](../RUNNING_Persian.md)

## مفهوم و سازوکار

لایه‌ای تشخیص دهید. فرمان پیدا نشد به نصب یا PATH، و شکست npm ممکن است به شبکه، مجوز، سیاست registry یا اختلاف lock مربوط باشد. خطای ماژول مرورگر ممکن است از file URL، MIME، فایل گمشده یا قانون مبدأ بیاید. به‌جای خاموش کردن امنیت مرورگر از سرور HTTP محلی استفاده کنید.

برای صفحهٔ خالی Console، Network و اولین ماژول خراب را ببینید. برای UI قدیمی مالک state، مرجع تغییرکرده، dependency اثر و کش را بررسی کنید. برای layout اندازهٔ محاسبه‌شده، overflow و stacking context را ببینید. پشتیبانی واقعی قابلیت در مرورگر هدف را کنترل کنید؛ تبدیل نحو همهٔ API گمشده را فراهم نمی‌کند. نمونهٔ کاهش‌یافته گزارش سازگاری را قابل اقدام می‌کند.

## خطاهای رایج

پاک کردن همهٔ کش‌ها ممکن است علت خطای انتشار را پنهان کند. پیش از ثبت خطای اصلی و نسخه‌ها همه‌چیز را دوباره نصب نکنید.

## تمرین و معیار پذیرش

برای ماژول گمشده، دادهٔ ذخیرهٔ خراب، درخواست مسدود و overflow یادداشت عیب‌یابی با یک بررسی تأییدی بنویسید.

## راهنمای حل

URL یا عملیات خراب را دقیق ثبت، لایه را بررسی، نمونه را کمینه، یک اصلاح اعمال و مسیر اصلی کاربر را دوباره اجرا کنید.
