# گزارش اعتبارسنجی

[English](VALIDATION_English.md) · [دوره](README_Persian.md) · [راهنمای بازتولید](RUNNING_Persian.md)

تاریخ نگارش و بررسی: 2026-11-18. محیط: Windows، Node v24.16.0 و npm 11.13.0. فرمان‌های shell با فرایند پایان‌پذیر cmd /c اجرا شدند. این گزارش بررسی محلی را پوشش می‌دهد؛ استقرار یا push انجام نشده است.

## بررسی‌های اجراشده

| بررسی | نتیجه |
| --- | --- |
| مستندات، جفت زبان، لینک محلی، پوشش کامل RTL، زبان کد و نحو JavaScript | موفق با scripts/check.mjs |
| تست اصلی دامنه و سرور HTTP | ۷ موفق، صفر ناموفق |
| شش مثال مستقل Node و TypeScript | خروجی مورد انتظار تأیید شد |
| بررسی نوع React و مثال مستقل TypeScript | موفق |
| ساخت production با Vite | موفق؛ dist تولید شد |
| تست سرتاسری Chromium بدون پنجره | ۸ موفق، صفر ناموفق |

پروژهٔ React با غیرفعال بودن install scriptها ۲۳ بسته نصب کرد. نسخهٔ مستقیم ثابت React و React DOM برابر 19.3.1، TypeScript برابر 7.0.2، Vite برابر 8.3.8 و بسته‌های نوع React برابر 19.3.0 است. بستهٔ اختیاری تست مرورگر در ریشه از Playwright نسخهٔ 1.65.1 استفاده می‌کند. هر دو بسته lockfile دارند. پس از آنکه اجرای اولیه نبود فایل مرورگر را گزارش کرد، Chrome Headless Shell با revision برابر 1255 نصب شد و اجرای کامل بعدی مرورگر موفق بود.

## رفتارهای بررسی‌شده

تست اصلی پول صحیح و نامعتبر، نرمال‌سازی جست‌وجو، گذار تغییرناپذیر کار، رکورد تکراری و بیش از حد، رد schema ذخیره، خطای HTTP، JSON خراب، لغو درخواست و مالکیت پاسخ قدیمی را می‌سنجد. تست سرور ارائهٔ HTML، وضعیت 404 و 405 و 503، مسیر محافظت‌شده، URL خراب، HEAD و جریان محدود SSE را بررسی می‌کند.

تست مرورگر جست‌وجو و reload و تاریخچه، نمایش لفظی عنوان شبیه markup، focus پس از toggle، ذخیره پس از reload، focus پس از حذف، حفظ دادهٔ خراب تا reset صریح، عرض 320 پیکسل، موفقیت و شکست fetch، خروجی worker، سه رخداد SSE و بسته شدن، و افزودن و فیلتر React را بررسی می‌کند.

مثال‌های Node با شمارهٔ 003 تا 007 و 010 اجرا شدند. مجموع 9700 سنت، closure مستقل و debounce، اصل شیء بدون تغییر، دستهٔ جایگزین، ترتیب حلقهٔ رخداد و خروجی حالت دارای نوع تأیید شد. مثال TypeScript جداگانه توسط کامپایلر هم بررسی شد؛ حذف نوع در Node به‌تنهایی بررسی نوع تلقی نشده است.

## بازتولید

از ریشهٔ دوره فرمان‌های دقیق [راهنمای اجرا](RUNNING_Persian.md) را اجرا کنید. بررسی اصلی نصب بسته نمی‌خواهد. ساخت React و تست مرورگر وابستگی مستقل و مرورگر Playwright می‌خواهند. سرور تست فقط loopback، پورت موقت و پایان خودکار توسط مجموعهٔ تست دارد.

خروجی dist، پوشهٔ node_modules و نتیجهٔ موقتی تست توسط .gitignore همین موضوع نادیده گرفته می‌شوند. کد، راهنما، تست نگهداری‌شده، تنظیمات و lockfile خروجی‌های قابل بازتولید هستند.

## محدودیت

استقرار production، احراز هویت API واقعی، پرداخت، تنظیم CDN، گردآوری Web Vitals میدانی و اتصال سرویس بیرونی آزمایش نشده است. رفتار صفحه‌خوان، انطباق کامل WCAG، آفلاین service worker، رگرسیون دیداری، Safari و Firefox و کارایی دستگاه واقعی به‌صورت دستی تأیید نشده‌اند. مثال این موضوع‌ها محتوای آموزشی با محدودیت صریح است. موفقیت تست ادعای آمادگی production یا تضمین مهارت ارشد نیست.
