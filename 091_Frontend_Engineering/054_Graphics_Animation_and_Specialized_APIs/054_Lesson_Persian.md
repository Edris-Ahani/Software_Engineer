# 054 — گرافیک و APIهای تخصصی

[English](./054_Lesson_English.md) · [مسیر دوره](../README_Persian.md) · [راهنمای اجرا](../RUNNING_Persian.md)

## مفهوم و سازوکار

SVG شکل برداری را در DOM و canvas پیکسل را با API دستوری رسم می‌کند؛ WebGL و WebGPU رندر مبتنی بر GPU با قابلیت و سازگاری متفاوت دارند. براساس تعداد شیء، تعامل، دسترس‌پذیری و دستگاه انتخاب کنید. تصویر canvas خودکار هر آیتم را به فناوری کمکی معرفی نمی‌کند.

حرکت باید از زمان سپری‌شده استفاده کند، نه نرخ فریم ثابت. کاهش حرکت را رعایت، کار غیرضروری در صفحهٔ پنهان را متوقف و buffer را متناسب با device pixel ratio بدون تخصیص بی‌حد تنظیم کنید. API تخصصی مانند موقعیت، clipboard، دوربین و اعلان شرط permission، secure context و فعال‌سازی کاربر دارند. مسیر مفید برای رد مجوز فراهم کنید.

## خطاهای رایج

پیش از توضیح هدف، مجوز دوربین یا اعلان نخواهید. پیکسل و لایهٔ GPU بیشتر می‌تواند به دستگاه کم‌حافظه آسیب بزند.

## تمرین و معیار پذیرش

نمودار canvas و جدول معادل را اجرا و resize کنید؛ مدیریت صفحهٔ پرچگالی و کاهش حرکت را توضیح دهید.

## راهنمای حل

جدول مرجع دادهٔ خوانا باشد، وضوح رسم محدود و اطلاعات بصری توضیح متنی داشته باشد.
