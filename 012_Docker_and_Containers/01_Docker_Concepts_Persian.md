# داکر و کانتینرها (Docker and Containers)

## چیست؟
داکر (Docker) یک پلتفرم متن‌باز است که استقرار (Deployment)، مقیاس‌پذیری و مدیریت برنامه‌ها را درون محیط‌های سبک و قابل حمل به نام **کانتینر (Container)** خودکار می‌کند. یک کانتینر، کد برنامه را به همراه تمامی وابستگی‌ها (Dependencies)، کتابخانه‌ها و فایل‌های پیکربندی آن بسته‌بندی می‌کند و تضمین می‌کند که برنامه در محیط‌های مختلف به صورت یکسان اجرا شود.

## ماشین‌های مجازی در برابر کانتینرها
- **ماشین‌های مجازی (VMs)**: شامل یک کپی کامل از سیستم‌عامل مهمان (Guest OS)، یک کپی مجازی از سخت‌افزار و برنامه هستند. آن‌ها سنگین هستند و زمان زیادی برای راه‌اندازی نیاز دارند.
- **کانتینرها**: هسته (Kernel) سیستم‌عامل میزبان را به اشتراک می‌گذارند و فقط پردازش‌های برنامه را ایزوله می‌کنند. آن‌ها بسیار سبک‌تر هستند، منابع کمتری مصرف می‌کنند و تقریباً بلافاصله راه‌اندازی می‌شوند.

## چه مشکلاتی را حل می‌کند؟
- **سندرم «روی سیستم من کار می‌کرد»**: تفاوت‌های بین محیط توسعه (Development)، تست و پروداکشن را از بین می‌برد. اگر برنامه در یک کانتینر داکر روی لپ‌تاپ شما اجرا شود، دقیقاً به همان شکل روی سرور پروداکشن هم اجرا خواهد شد.
- **استقرار مایکروسرویس‌ها**: کانتینرها بهترین گزینه برای معماری مایکروسرویس هستند و به شما اجازه می‌دهند صدها سرویس کوچک و ایزوله را به طور مستقل مستقر و مقیاس‌پذیر (Scale) کنید.
- **بهره‌وری منابع**: در مقایسه با ماشین‌های مجازی سنتی، می‌توانید تعداد بسیار بیشتری کانتینر را روی یک ماشین فیزیکی واحد اجرا کنید.

## مفاهیم کلیدی
- **Dockerfile**: یک فایل متنی حاوی تمامی دستوراتی که یک کاربر می‌تواند برای ساخت یک Image فراخوانی کند.
- **Image**: یک قالب فقط-خواندنی (Read-only) شامل دستورالعمل‌هایی برای ایجاد کانتینر داکر. این دقیقاً شبیه به یک عکس (Snapshot) از برنامه شما و محیط اجرای آن است.
- **Container**: یک نمونه در حال اجرا (Runnable instance) از یک Image.

## مثال‌ها

### یک Dockerfile ساده برای Node.js
```dockerfile
# 1. Use the official Node.js image as the base image
FROM node:18-alpine

# 2. Set the working directory inside the container
WORKDIR /app

# 3. Copy package.json and install dependencies
COPY package*.json ./
RUN npm install

# 4. Copy the rest of the application code
COPY . .

# 5. Expose the port the app runs on
EXPOSE 3000

# 6. Define the command to run the app
CMD ["node", "app.js"]
```
