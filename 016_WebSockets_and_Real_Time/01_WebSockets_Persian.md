# وب‌سوکت‌ها (WebSockets) و ارتباط بلادرنگ (Real-Time)

## چیست؟
وب‌سوکت (WebSocket) یک پروتکل ارتباطی کامپیوتری است که کانال‌های ارتباطی دوطرفه (Full-duplex) را بر روی یک اتصال واحد TCP فراهم می‌کند. برخلاف HTTP که صرفاً بر اساس ساختار درخواست-پاسخ کار می‌کند (کلاینت باید داده را درخواست کند، سرور پاسخ می‌دهد و سپس ارتباط بسته می‌شود)، وب‌سوکت‌ها اتصال را باز نگه می‌دارند؛ این موضوع به سرور اجازه می‌دهد تا در هر زمانی که بخواهد، داده‌ها را به سمت کلاینت پوش (Push) کند.

## جایگزین‌های وب‌سوکت
- **HTTP Polling (سرکشی مداوم)**: کلاینت هر چند ثانیه یک بار از سرور می‌پرسد که آیا داده جدیدی وجود دارد یا خیر. (بسیار ناکارآمد است).
- **Long Polling (سرکشی طولانی)**: کلاینت از سرور درخواست داده می‌کند. سرور اتصال را تا زمانی که داده جدیدی نداشته باشد باز نگه می‌دارد، سپس آن را ارسال کرده و ارتباط را می‌بندد. کلاینت بلافاصله دوباره متصل می‌شود.
- **رویدادهای ارسالی از سرور (SSE - Server-Sent Events)**: یک ارتباط یک‌طرفه است که سرور می‌تواند آپدیت‌ها را برای کلاینت پوش کند. برای مواردی مثل فید اخبار یا نتایج زنده مسابقات ورزشی خوب است، اما برای چت دوطرفه مناسب نیست.

## چه مشکلاتی را حل می‌کند؟
- **آپدیت‌های بلادرنگ (Real-time)**: امکاناتی مانند چت زنده، بازی‌های چندنفره، ویرایش مشارکتی (مانند Google Docs) و تابلوهای زنده بورس را با کمترین تأخیر ممکن می‌سازد.
- **کاهش بار اضافه (Overhead)**: از بار اضافه‌ی هدرهای بزرگ HTTP که در صورت ارسال هزاران درخواست HTTP در ثانیه برای داده‌های زنده ایجاد می‌شود، جلوگیری می‌کند.

## چه زمانی و کجا از آن استفاده کنیم؟
زمانی از وب‌سوکت‌ها استفاده کنید که به ارتباط دوطرفه، بلادرنگ و با تأخیر کم بین کلاینت و سرور نیاز دارید. برای عملیات ساده CRUD (ساخت، خواندن، آپدیت، حذف) که APIهای سنتی REST برای آن‌ها مناسب‌تر و راحت‌تر قابل کش (Cache) شدن هستند، از وب‌سوکت استفاده نکنید.

## مثال‌ها

### مثال Node.js (با استفاده از کتابخانه `socket.io`)

**سمت سرور:**
```javascript
const io = require('socket.io')(3000);

io.on('connection', (socket) => {
    console.log('A user connected:', socket.id);

    // Listen for a message from the client
    socket.on('chat message', (msg) => {
        console.log('Message received:', msg);
        
        // Broadcast the message to all connected clients
        io.emit('chat message', msg);
    });

    socket.on('disconnect', () => {
        console.log('User disconnected');
    });
});
```

**سمت کلاینت (مرورگر):**
```html
<script src="https://cdn.socket.io/4.0.0/socket.io.min.js"></script>
<script>
    const socket = io('http://localhost:3000');

    // Send a message
    socket.emit('chat message', 'Hello World!');

    // Receive messages
    socket.on('chat message', function(msg) {
        console.log('New message:', msg);
    });
</script>
```
