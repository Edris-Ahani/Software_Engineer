# پارادایم‌های دیتابیس: SQL در برابر NoSQL

## چیست؟
هنگام طراحی یک بک‌اند، انتخاب دیتابیس مناسب بسیار حیاتی است. دیتابیس‌ها به طور کلی به دو دسته اصلی تقسیم می‌شوند: رابطه‌ای (SQL) و غیررابطه‌ای (NoSQL).

## ۱. پایگاه داده‌های SQL (رابطه‌ای)
- **ساختار**: داده‌ها در جداول با شمای (Schema) سخت‌گیرانه (ردیف‌ها و ستون‌ها) ذخیره می‌شوند.
- **روابط**: جداول با استفاده از کلیدهای خارجی (Foreign Keys) به یکدیگر متصل می‌شوند.
- **ویژگی‌ها (ACID)**:
  - *اتمیک بودن (Atomicity)*: یک تراکنش یا کاملاً انجام می‌شود یا اصلاً انجام نمی‌شود (صفر یا صد).
  - *سازگاری (Consistency)*: داده‌ها باید همیشه طبق قوانین تعریف شده معتبر باشند.
  - *انزوا (Isolation)*: تراکنش‌های همزمان با یکدیگر تداخل ندارند.
  - *دوام (Durability)*: پس از ثبت یک تراکنش، حتی در صورت خرابی سیستم، داده‌ها ذخیره باقی می‌مانند.
- **مثال‌ها**: PostgreSQL, MySQL, Microsoft SQL Server, Oracle.
- **بهترین کاربرد برای**: سیستم‌هایی که نیاز به کوئری‌های پیچیده، یکپارچگی دقیق داده‌ها (مانند برنامه‌های مالی) و روابط شفاف دارند.

## ۲. پایگاه داده‌های NoSQL (غیررابطه‌ای)
- **ساختار**: داده‌ها می‌توانند به روش‌های مختلف بدون شمای ثابت ذخیره شوند (مانند اسناد JSON، جفت‌های کلید-مقدار، یا گراف‌ها).
- **ویژگی‌ها (BASE)**:
  - *اساساً در دسترس (Basically Available)*: سیستم تضمین می‌کند که همیشه در دسترس باشد.
  - *وضعیت نرم (Soft state)*: وضعیت سیستم ممکن است حتی بدون دریافت ورودی جدید تغییر کند (به دلیل سازگاری نهایی).
  - *سازگاری نهایی (Eventual consistency)*: سیستم در نهایت و با گذشت زمان به یکپارچگی و سازگاری می‌رسد.
- **انواع و مثال‌ها**:
  - *مبتنی بر سند (Document)*: MongoDB, CouchDB.
  - *کلید-مقدار (Key-Value)*: Redis, DynamoDB.
  - *خانواده-ستون (Column-Family)*: Cassandra, HBase.
  - *گراف (Graph)*: Neo4j.
- **بهترین کاربرد برای**: توسعه سریع با داده‌های بدون ساختار، مقیاس‌پذیری افقی بسیار بالا، تحلیل‌های بلادرنگ و کشینگ.

## نحوه انتخاب
شما مجبور نیستید همیشه فقط یکی را انتخاب کنید. بسیاری از سیستم‌های مدرن از رویکرد **ماندگاری چندگانه (Polyglot Persistence)** استفاده می‌کنند: استفاده از PostgreSQL برای داده‌های تراکنشی اصلی، Redis برای کش کردن، و MongoDB برای کاتالوگ محصولات با ساختار متغیر.
