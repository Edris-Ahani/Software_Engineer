# NTP Server — راهنمای همگام‌سازی ساعت در شبکه

این فصل توضیح می‌دهد سرور NTP چیست، چرا ساعت درست برای نرم‌افزار و زیرساخت ضروری است، در چه محیط‌هایی استفاده می‌شود و چطور وضعیت آن را بررسی کنیم. مطالعه به دانش مقدماتی شبکه نیاز دارد؛ برای درک مبانی، اجرای دستورات ضروری نیست.

## مسیر مطالعه

1. **شناخت مسئله:** ساعت سیستم، UTC، منطقهٔ زمانی و دلیل اختلاف ساعت دستگاه‌ها.
2. **نحوهٔ کار:** کلاینت و سرور، Stratum، چهار timestamp و اصلاح تدریجی ساعت.
3. **کاربردها:** لاگ و مانیتورینگ، احراز هویت، دیتابیس، زیرساخت، دوربین و تجهیزات صنعتی.
4. **طراحی و امنیت:** منابع مستقل، سرور داخلی، شبکهٔ بدون اینترنت، NTS و تفاوت NTP با PTP.
5. **کار عملی:** بررسی Windows Time، نمونهٔ تنظیمات chrony در Linux، پایش و عیب‌یابی.
6. **مرور:** اشتباهات رایج، تمرین‌های پاسخ‌دار و منابع رسمی برای مطالعهٔ بیشتر.

نمونه‌های تنظیمات، آموزشی هستند و باید با نام سرورها و سیاست شبکهٔ واقعی تطبیق داده شوند. مثال‌های Windows در Command Prompt و مثال‌های Linux داخل سیستم Linux اجرا می‌شوند. هیچ‌یک از تنظیمات این فصل به‌صورت خودکار روی سیستم اعمال نمی‌شود.
