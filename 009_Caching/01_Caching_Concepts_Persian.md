# کشینگ (Caching)

## چیست؟
کشینگ فرآیند ذخیره‌سازی کپی‌هایی از فایل‌ها یا داده‌ها در یک مکان ذخیره‌سازی موقت (کش) است تا بتوان سریع‌تر به آن‌ها دسترسی پیدا کرد. در توسعه بک‌اند، کشینگ معمولاً برای ذخیره نتایج کوئری‌های سنگین دیتابیس، فراخوانی‌های API خارجی یا محاسبات پیچیده استفاده می‌شود.

## انواع کشینگ
۱. **کش سمت کلاینت/مرورگر**: ذخیره فایل‌های استاتیک (HTML, CSS, JS, تصاویر) در مرورگر کاربر.
۲. **شبکه توزیع محتوا (CDN)**: کش کردن فایل‌های استاتیک در سرورهایی که در سطح جهانی توزیع شده‌اند تا به کاربران نزدیک‌تر باشند.
۳. **کش سرور وب**: کش کردن پاسخ‌ها مستقیماً در سطح سرور وب (مثل Nginx).
۴. **کش برنامه/دیتابیس**: ذخیره رکوردهای دیتابیس که زیاد به آن‌ها نیاز است در حافظه موقت یا RAM (مانند Redis یا Memcached).

## چه مشکلاتی را حل می‌کند؟
- **کاهش تاخیر (Latency)**: بازیابی داده‌ها از حافظه (RAM) بسیار سریع‌تر از خواندن آن‌ها از دیسک (دیتابیس) یا شبکه است.
- **کاهش بار (Load)**: از فشار بیش از حد و کوئری‌های تکراری روی پایگاه داده اصلی جلوگیری می‌کند و مانع از کرش کردن سیستم در زمان ترافیک بالا می‌شود.
- **صرفه‌جویی در هزینه**: میزان پردازش مورد نیاز در سرورهای گران‌قیمت دیتابیس را کاهش می‌دهد.

## چه زمانی و کجا از آن استفاده کنیم؟
از کشینگ برای داده‌هایی استفاده کنید که به دفعات زیاد خوانده می‌شوند اما کمتر تغییر می‌کنند (نسبت بالای خواندن به نوشتن). نمونه‌ها شامل نشست‌های کاربری (Sessions)، کاتالوگ محصولات، تنظیمات پیکربندی، یا جدول امتیازات روزانه است.

## استراتژی‌های رایج کشینگ
- **Cache-Aside (بارگذاری تنبل)**: برنامه ابتدا کش را بررسی می‌کند. اگر داده نبود (Miss)، آن را از دیتابیس می‌خواند، در کش ذخیره می‌کند و سپس برمی‌گرداند.
- **Write-Through**: داده‌ها به طور همزمان هم در کش و هم در پایگاه داده نوشته می‌شوند.

## مثال‌ها

### مثال Node.js (استفاده از Redis با استراتژی Cache-Aside)
```javascript
const redis = require('redis');
const client = redis.createClient();

async function getUserProfile(userId) {
    // 1. Check if data is in the cache
    const cachedProfile = await client.get(`user:${userId}`);
    
    if (cachedProfile) {
        // Cache Hit
        return JSON.parse(cachedProfile);
    }
    
    // 2. Cache Miss - Fetch from Database
    const dbProfile = await database.query('SELECT * FROM users WHERE id = ?', [userId]);
    
    if (dbProfile) {
        // 3. Save to cache for future requests (with a time-to-live of 3600 seconds)
        await client.setEx(`user:${userId}`, 3600, JSON.stringify(dbProfile));
    }
    
    return dbProfile;
}
```
