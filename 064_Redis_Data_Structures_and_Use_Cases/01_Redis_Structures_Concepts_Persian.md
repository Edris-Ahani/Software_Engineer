# ساختارهای داده در ردیس (Redis) و کاربردهای پیشرفته

## فراتر از یک کَشِ ساده
بیشتر توسعه‌دهندگان از Redis فقط به عنوان یک مخزن کلید-مقدار (Key-Value) ساده برای کش کردنِ رشته‌های JSON استفاده می‌کنند (`SET user:1 "{...}"`). اما ردیس در واقع یک "سرورِ ساختار داده (Data Structure Server)" است. شناخت ساختارهای داخلیِ آن به شما اجازه می‌دهد تا مشکلات پیچیده‌ی مهندسی را در کسری از ثانیه و بدون نیاز به نوشتن کوئری‌های سنگین SQL حل کنید.

## ۱. رشته‌ها (Strings)
- **کاربرد**: کَش کردن HTML، JSON یا شمارش بازدیدِ صفحات.
- **مثال**: دستور `INCR article:100:views`. ردیس اعداد را به صورت اتمیک (Atomic) افزایش می‌دهد، در نتیجه برای ساخت شمارنده‌های بلادرنگ (مثل بازدید ویدیو در یوتیوب) بدون درگیری با مشکل Race Condition کاملاً بی‌نقص است.

## ۲. هش‌ها (Hashes)
- **مفهوم**: یک Map (یا دیکشنری) در داخل یک کلید ردیس.
- **کاربرد**: ذخیره پروفایل کاربران. به جای اینکه یک رشته عظیم JSON را فقط برای تغییر سن کاربر واکشی (Fetch) کنید، می‌توانید فقط همان فیلد خاص را آپدیت کنید: `HSET user:1 age 25`.

## ۳. لیست‌ها (Lists)
- **مفهوم**: یک لیست پیوندی (Linked List) از رشته‌ها.
- **کاربرد**: ساخت صف‌های پیامِ ساده یا فید "فعالیت‌های اخیر". به عنوان مثال، برای نگهداریِ ۱۰ جستجوی اخیر کاربر: `LPUSH user:1:searches "shoes"` و سپس اجرای `LTRIM user:1:searches 0 9` برای نگه داشتنِ فقط ۱۰ آیتم آخر.

## ۴. مجموعه‌ها (Sets)
- **مفهوم**: مجموعه‌ای نامرتب از رشته‌های *منحصربه‌فرد (بدون تکرار)*.
- **کاربرد**: ردیابی آدرس‌های IP یونیکی که امروز از سایت بازدید کرده‌اند، یا پیاده‌سازی سیستم "دنبال‌کنندگان (Followers)". با گرفتنِ اشتراک (`SINTER`) بین مجموعه دوستانِ دو کاربر، می‌توانید "دوستان مشترک (Mutual Friends)" آن‌ها را در کسری از ثانیه پیدا کنید.

## ۵. مجموعه‌های مرتب‌شده (Sorted Sets / ZSETs)
- **مفهوم**: مجموعه‌ای که هر عضو آن یک "امتیاز (Score)" دارد. ردیس به طور خودکار این مجموعه را بر اساس امتیازِ اعضا مرتب نگه می‌دارد.
- **کاربرد**: ساخت تابلو امتیازاتِ بلادرنگ (Leaderboards در بازی‌ها)، یا سیستم محدودیتِ نرخ (Rate Limiting). مثلاً: `ZADD global_leaderboard 9500 "Player_1"`. شما می‌توانید فوراً ۱۰ بازیکن برتر را (`ZREVRANGE`) استخراج کنید، بدون اینکه نیاز باشد یک کوئری بسیار کُندِ `ORDER BY` را در دیتابیسِ رابطه‌ای اجرا کنید.
