# مفاهیم CI/CD (یکپارچگی و استقرار مداوم)

## چیست؟
CI/CD روشی برای تحویل مکرر برنامه‌ها به مشتریان با وارد کردن اتوماسیون (Automation) به مراحل توسعه برنامه است. مفاهیم اصلی آن شامل یکپارچگی مداوم (Continuous Integration)، تحویل مداوم (Continuous Delivery) و استقرار مداوم (Continuous Deployment) است.

## مفاهیم کلیدی
- **یکپارچگی مداوم (CI)**: روشی برای خودکارسازی ادغام تغییرات کدهای توسعه‌دهندگان مختلف در یک پروژه نرم‌افزاری واحد است. وقتی توسعه‌دهندگان کد خود را به یک مخزن (مثل گیت‌هاب) Push می‌کنند، تست‌ها و بیلدها (Builds) به صورت خودکار اجرا می‌شوند تا اطمینان حاصل شود که کد جدید چیزی را خراب نکرده است.
- **تحویل مداوم (CD - Continuous Delivery)**: توسعه‌ای بر روی CI است. این روش تضمین می‌کند که می‌توانید تغییرات جدید را به سرعت و به روشی پایدار به دست مشتریان برسانید. کد در هر لحظه آماده استقرار است، اما استقرار نهایی در محیط پروداکشن (Production) به صورت دستی انجام می‌شود.
- **استقرار مداوم (CD - Continuous Deployment)**: یک قدم فراتر از تحویل مداوم است. هر تغییری که تمام مراحل پایپ‌لاین (Pipeline) را با موفقیت پشت سر بگذارد، بدون هیچ‌گونه دخالت انسانی و به صورت کاملاً خودکار به مشتریان تحویل داده می‌شود (مستقر می‌شود).

## چه مشکلاتی را حل می‌کند؟
- **جهنم یکپارچه‌سازی (Integration Hell)**: توسعه‌دهندگان دیگر روزها یا هفته‌ها را صرف ادغام کردن (Merge) برنچ‌های خود با یکدیگر نمی‌کنند.
- **خطاهای دستی (Manual Errors)**: خودکارسازی فرآیند بیلد و استقرار، احتمال خطای انسانی در هنگام انتشار نسخه‌های جدید را از بین می‌برد.
- **چرخه‌های انتشار کند**: شرکت‌ها به جای اینکه هر چند ماه یک بار آپدیت بدهند، می‌توانند ویژگی‌های جدید یا اصلاحات باگ را چندین بار در روز منتشر کنند.

## چه زمانی و کجا از آن استفاده کنیم؟
CI/CD باید در تقریباً تمام پروژه‌های نرم‌افزاری مدرن استفاده شود. ابزارهای محبوب شامل **GitHub Actions**، **GitLab CI**، **Jenkins** و **CircleCI** هستند.

## مثال‌ها

### پایپ‌لاین ساده با GitHub Actions (YAML)
```yaml
name: Node.js CI

on:
  push:
    branches: [ "main" ]
  pull_request:
    branches: [ "main" ]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v3
    - name: Use Node.js
      uses: actions/setup-node@v3
      with:
        node-version: '18.x'
    - run: npm ci
    - run: npm run build --if-present
    - run: npm test
```
