# مبانی تست نرم‌افزار (Software Testing)

## چیست؟
تست نرم‌افزار در توسعه بک‌اند عملی است برای ارزیابی و تأیید اینکه یک برنامه نرم‌افزاری یا اجزای خاص آن دقیقاً همان‌طور که انتظار می‌رود کار می‌کنند. تست خودکار (Automated Testing) شامل نوشتن کدهایی است که کدهای اصلی (Production) شما را تست می‌کنند.

## انواع تست
۱. **تست واحد (Unit Tests)**: تست کوچک‌ترین اجزای مستقل کد (مانند یک تابع یا کلاس مجزا) به صورت ایزوله. از Mock و Stub برای شبیه‌سازی وابستگی‌های خارجی (مثل دیتابیس‌ها) استفاده می‌شود.
۲. **تست یکپارچه‌سازی (Integration Tests)**: تأیید اینکه ماژول‌ها یا سرویس‌های مختلف به درستی با هم کار می‌کنند. برای مثال، تست اینکه آیا برنامه داده‌ها را به درستی در یک دیتابیس واقعی یا تستی ذخیره می‌کند.
۳. **تست End-to-End (E2E)**: تست کل جریان برنامه از ابتدا تا انتها با شبیه‌سازی سناریوهای کاربر واقعی (از فراخوانی API تا دیتابیس و بازگشت به کاربر).

## چه مشکلاتی را حل می‌کند؟
- **رگرسیون (Regressions)**: از این جلوگیری می‌کند که تغییرات جدید باعث خراب شدن ویژگی‌های فعلی که از قبل درست کار می‌کردند بشود.
- **اعتماد به نفس**: به توسعه‌دهندگان اعتماد به نفس می‌دهد تا کد را ریفکتور و بهینه‌سازی کنند، با این اطمینان که تست‌ها هر اشتباهی را متوجه می‌شوند.
- **مستندسازی**: تست‌های خوب نوشته شده به عنوان یک مستندات زنده عمل می‌کنند که نشان می‌دهند کد دقیقاً چه کاری قرار است انجام دهد.
- **کاهش باگ**: باگ‌ها را در مراحل اولیه توسعه و قبل از رسیدن به محیط پروداکشن (Production) شناسایی می‌کند.

## چه زمانی و کجا از آن استفاده کنیم؟
تست کردن باید بخش پیوسته‌ای از چرخه توسعه باشد و معمولاً در یک پایپ‌لاین CI/CD خودکار می‌شود. هر بلوک منطقی مهم، حالت‌های لبه (Edge cases) و جریان‌های حیاتی کاربر باید دارای تست‌های خودکار باشند.

## مثال‌ها

### مثال Node.js (تست واحد با فریم‌ورک Jest)
```javascript
// math.js
function add(a, b) {
    return a + b;
}
module.exports = { add };

// math.test.js
const { add } = require('./math');

describe('Math Operations', () => {
    
    // A single Unit Test
    test('should correctly add two numbers', () => {
        // Arrange
        const num1 = 5;
        const num2 = 10;
        
        // Act
        const result = add(num1, num2);
        
        // Assert
        expect(result).toBe(15);
    });
    
});
```
