# مستندسازی API (استاندارد OpenAPI/Swagger)

## چیست؟
مستندسازی API (API Documentation) یک محتوای فنی است که حاوی دستورالعمل‌هایی در مورد نحوه استفاده موثر و ادغام با یک API می‌باشد. مشخصات **OpenAPI** (که قبلاً با نام **Swagger** شناخته می‌شد) یک فرمت استاندارد برای توصیف APIهای REST است.

## مفاهیم کلیدی
- **مشخصات OpenAPI (OAS)**: یک رابط استاندارد و مستقل از زبان برای APIهای RESTful است که به انسان‌ها و رایانه‌ها اجازه می‌دهد قابلیت‌های سرویس را بدون دسترسی به کد منبع، کشف و درک کنند. این مشخصات معمولاً به زبان YAML یا JSON نوشته می‌شود.
- **رابط کاربری Swagger UI**: مجموعه‌ای از فایل‌های HTML، Javascript و CSS است که به صورت پویا (داینامیک) مستندات زیبایی را از روی یک API سازگار با OAS تولید می‌کند. این ابزار به همه اجازه می‌دهد تا بدون نیاز به نوشتن هیچ کدی، منابع API را تجسم کرده و مستقیماً با آن‌ها تعامل داشته باشند (درخواست بفرستند).

## چه مشکلاتی را حل می‌کند؟
- **همکاری فرانت‌اند و بک‌اند**: به جای اینکه توسعه‌دهندگان بک‌اند به صورت شفاهی یا در فایل‌های به هم ریخته توضیح دهند که API چگونه کار می‌کند، مستندات به عنوان "منبع واحد حقیقت" (Single Source of Truth) برای تیم فرانت‌اند عمل می‌کند.
- **تولید خودکار کلاینت (Client Generation)**: بر اساس فایل OpenAPI، می‌توانید SDKهای کلاینت را به صورت خودکار در زبان‌های مختلف (مانند تایپ‌اسکریپت، پایتون، جاوا و غیره) تولید کنید.
- **تست تعاملی**: به توسعه‌دهندگان و مصرف‌کنندگان شخص ثالث اجازه می‌دهد تا اندپوینت‌های API را مستقیماً از روی صفحه مستندات در مرورگر خود تست کنند.

## سایر ابزارهای محبوب API
- **Postman / Insomnia**: نرم‌افزارهای رابط کاربری گرافیکی (GUI) قدرتمندی هستند که برای توسعه، تست، اشتراک‌گذاری و مستندسازی APIها استفاده می‌شوند.

## مثال‌ها

### مثال مشخصات OpenAPI (فرمت YAML)
```yaml
openapi: 3.0.0
info:
  title: Simple User API
  version: 1.0.0
paths:
  /users/{id}:
    get:
      summary: Returns a user by ID
      parameters:
        - name: id
          in: path
          required: true
          schema:
            type: integer
      responses:
        '200':
          description: A user object
          content:
            application/json:
              schema:
                type: object
                properties:
                  id:
                    type: integer
                  name:
                    type: string
        '404':
          description: User not found
```
