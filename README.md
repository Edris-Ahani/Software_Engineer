# The Ultimate Software Engineering Handbook

Welcome to the **Software Engineering Handbook** repository! This project serves as a comprehensive, bilingual (English & Persian) knowledge base covering everything a modern Software Engineer and System Architect needs to know.

From foundational SOLID principles and Clean Code, to advanced System Design, Distributed Systems, Cloud-Native Architectures, and Security — this repository is designed to be the ultimate reference guide.

## 📚 What's Inside?
This repository is organized into 78 distinct chapters, each focusing on a critical engineering concept. Some of the major domains covered include:

- **Clean Architecture & Code Quality:** SOLID, DRY, KISS, Dependency Injection (IoC), Semantic Versioning.
- **System Design & Distributed Systems:** Microservices, Saga Pattern, CAP Theorem, Service Mesh, API Gateways, Load Balancing.
- **Networking & Protocols:** gRPC vs REST, WebSockets, Server-Sent Events, SSL/TLS Handshakes, Reverse Proxies.
- **Database & Data Storage:** B-Tree Indexes, Elasticsearch (Inverted Index), Redis Data Structures, Zero-Downtime Migrations, Sharding.
- **Security (OWASP):** SQL Injection, XSS, CSRF, CORS, JWT vs Sessions, OAuth2.
- **DevOps & Infrastructure:** Docker, Kubernetes, CI/CD, Deployment Strategies (Blue/Green, Canary).

## 🗂️ Structure
Each topic is encapsulated in its own numbered directory for easy navigation. Inside every directory, you will find:
1. `..._English.md`: An in-depth explanation of the concept in English.
2. `..._Persian.md`: A localized, highly detailed explanation of the concept in Persian.

All code snippets, architectural examples, and best practices are fully contained within these Markdown files, ensuring maximum portability and readability.

# هندبوک جامع مهندسی نرم‌افزار

به مخزن **هندبوک مهندسی نرم‌افزار** خوش آمدید! این پروژه یک پایگاه دانشِ دوزبانه (انگلیسی و فارسی) و بسیار جامع است که تمام مفاهیمی را که یک مهندس نرم‌افزار مدرن و معمار سیستم باید بداند، پوشش می‌دهد.

از اصول پایه‌ی SOLID و کدنویسی تمیز گرفته تا طراحی سیستم‌های پیشرفته، سیستم‌های توزیع‌شده، معماری‌های ابری و امنیت؛ این مخزن طراحی شده تا کامل‌ترین مرجع دم‌دستیِ شما باشد.

## 📚 چه چیزهایی در این پروژه وجود دارد؟
این مخزن به ۷۸ فصل مجزا تقسیم شده است که هر کدام روی یک مفهوم کلیدی مهندسی تمرکز دارند. برخی از حوزه‌های اصلی عبارتند از:

- **معماری و کیفیت کد:** اصول SOLID، تمیزی کد (Clean Code)، تزریق وابستگی (DI) و نسخه‌گذاری معنایی.
- **طراحی سیستم‌های توزیع‌شده:** مایکروسرویس‌ها، الگوی Saga، قضیه CAP، Service Mesh و API Gateway.
- **شبکه و پروتکل‌ها:** تفاوت gRPC و REST، وب‌سوکت‌ها، دست‌دادن SSL/TLS و پروکسی‌های معکوس.
- **دیتابیس و ذخیره‌سازی داده:** ایندکس‌های B-Tree، الاستیک‌سرچ، ساختارهای داده Redis، مایگریشن‌های بدون قطعی و Sharding.
- **امنیت:** تزریق SQL، حملات XSS و CSRF، مکانیزم CORS و مقایسه JWT با Session.
- **دواپس و زیرساخت:** داکر، کوبرنیتیز و استراتژی‌های استقرار کدهای جدید (Blue/Green و Canary).

## 🗂️ ساختار پروژه
هر مبحث در یک پوشه شماره‌گذاری‌شده قرار دارد تا دسترسی به آن‌ها آسان باشد. درون هر پوشه موارد زیر را پیدا خواهید کرد:
