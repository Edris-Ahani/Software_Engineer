# نسخه‌گذاری معنایی (Semantic Versioning / SemVer)

## چیست؟
وقتی شما یک بسته نرم‌افزاری، یک API یا یک کتابخانه منتشر می‌کنید، به یک روش استاندارد نیاز دارید تا به بقیه برنامه‌نویسان بگویید چه چیزی تغییر کرده است. **نسخه‌گذاری معنایی (SemVer)** استاندارد جهانی برای شماره‌گذاری است که به فرمت `MAJOR.MINOR.PATCH` (مثلاً `v2.14.3`) نوشته می‌شود.

## ۱. شماره اصلی (MAJOR) - تغییرات مخرب
- **فرمت**: افزایش شماره از `1.0.0` به `2.0.0`.
- **زمان استفاده**: وقتی شما **تغییرات ناسازگار و مخرب (Breaking Changes)** ایجاد می‌کنید. اگر یک تابع را حذف کنید، ساختار JSON خروجی API را عوض کنید، یا پارامتری که قبلاً اختیاری بود را اجباری کنید، الزاماً باید نسخه Major را بالا ببرید.
- **معنی**: توسعه‌دهندگانی که به این نسخه آپدیت می‌کنند، حتماً باید بخش‌هایی از کد خود را بازنویسی کنند، در غیر این صورت برنامه‌ی آن‌ها کِرَش خواهد کرد.

## ۲. شماره فرعی (MINOR) - ویژگی‌های جدید
- **فرمت**: افزایش شماره از `2.1.0` به `2.2.0` (و صفر شدن شماره PATCH).
- **زمان استفاده**: وقتی شما قابلیت‌های جدیدی را به روشی **سازگار با گذشته (Backwards-compatible)** اضافه می‌کنید. مثلاً اضافه کردن یک مسیر جدید به API، یا اضافه کردن یک پارامتر کاملاً اختیاریِ جدید به یک تابع.
- **معنی**: توسعه‌دهندگان می‌توانند با خیال راحت آپدیت کنند. کدهای قبلیِ آن‌ها بدون هیچ مشکلی به کار خود ادامه خواهند داد.

## ۳. شماره پَچ (PATCH) - رفع باگ
- **فرمت**: افزایش شماره از `2.1.3` به `2.1.4`.
- **زمان استفاده**: وقتی شما تغییراتی برای **رفع باگ** (بدون از بین بردن سازگاری با گذشته) اعمال می‌کنید. مثلاً رفع مشکل نشت حافظه یا برطرف کردن یک خطای محاسباتی.
- **معنی**: توسعه‌دهندگان همیشه باید برای حفظ امنیت و ثبات سیستم، بلافاصله نرم‌افزار خود را به آخرین نسخه Patch آپدیت کنند.

## علامت‌های Caret (^) و Tilde (~) در package.json
اگر به پکیج‌منیجرهایی مثل NPM نگاه کنید:
- `"react": "^18.2.0"` یعنی: هر آپدیت Minor یا Patch (مثل `18.3.0`) را به طور خودکار نصب کن، اما هرگز `19.0.0` (Major) را به طور خودکار نصب نکن، چون ممکن است کدهای من را خراب کند!
- `"react": "~18.2.0"` یعنی: فقط آپدیت‌های رفع باگ یا Patch (مثل `18.2.1`) را نصب کن و قابلیت‌های جدید (Minor) را به طور خودکار دریافت نکن.
