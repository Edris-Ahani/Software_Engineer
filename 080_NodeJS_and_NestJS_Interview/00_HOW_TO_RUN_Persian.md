# نحوه اجرای مثال‌ها

اول یک‌بار وابستگی‌ها را نصب کنید:

</div>

```bash
cd 080_NodeJS_and_NestJS_Interview
npm install
```

<div dir="rtl" style="text-align: right;">

سپس هر بخش را با شماره همان قسمت اجرا کنید:

</div>

```bash
npm run 001
npm run 002
npm run 003
npm run 004
npm run 005
npm run 006
npm run 007
npm run 008
npm run 009
npm run 010
npm run 011
npm run 012
npm run 013
npm run 014
npm run 015
npm run 016
```

<div dir="rtl" style="text-align: right;">

| شماره | موضوع |
|------:|:------|
| `001` | مدل اجرا و معماری `Node.js` |
| `002` | `Event Loop` و صف‌ها |
| `003` | `Callback` / `Promise` / `async-await` |
| `004` | سیستم ماژول `CJS`/`ESM` |
| `005` | `Stream` و `Buffer` |
| `006` | `EventEmitter` و چندپردازشی |
| `007` | `HTTP` و کارایی |
| `008` | خطاها و ابزارهای runtime |
| `009` | معماری هسته `NestJS` |
| `010` | تزریق وابستگی (`DI`) |
| `011` | مسیر درخواست (`Middleware`…`Filter`) |
| `012` | دکوراتورها و `DTO` |
| `013` | ماژول پویا و lifecycle |
| `014` | قابلیت‌های پیشرفته |
| `015` | `TestingModule` |
| `016` | ترکیب‌های سطح ارشد |

همهٔ مثال‌های `NestJS` خودشان سرور را بالا می‌آورند، درخواست می‌زنند، خروجی را چاپ می‌کنند و خارج می‌شوند.

</div>
