# نحوه اجرای مثال‌ها

بانک سؤال در دو فایل [فارسی](01_NodeJS_NestJS_Interview_Persian.md) و [انگلیسی](01_NodeJS_NestJS_Interview_English.md)، هرکدام با ۲۲۳ سؤال و ۳۲ بخش، نگهداری می‌شود. مثال‌ها برای مطالعه و مشاهدهٔ رفتار هستند؛ احراز هویت نمایشی با header جایگزین احراز هویت production نیست.

**پیش‌نیاز:** APIهای مثال‌ها با Node.js 20.19+ سازگارند؛ برای استفادهٔ واقعی نسخهٔ پشتیبانی‌شدهٔ روز را انتخاب کنید. packageها روی NestJS 10 و Express 4 موجود پروژه باقی می‌مانند؛ نمونه‌های NestJS 11 را بدون بررسی migration روی این وابستگی‌ها اجرا نکنید.

اول یک‌بار وابستگی‌ها را از lockfile نصب کنید؛ این دستور پوشهٔ node_modules همین پروژه را بازسازی می‌کند:

</div>

```bash
cd 080_NodeJS_and_NestJS_Interview
npm ci
```

<div dir="rtl" style="text-align: right;">

</div>

مثال‌های HTTP خودشان سرور را بالا می‌آورند، درخواست می‌زنند و خارج می‌شوند. مثال جدید `019` فقط روی loopback با پورت آزاد اجرا و در finally بسته می‌شود؛ `020` فقط TestingModule دارد و سرور باز نمی‌کند. مثال‌های جدید به دیتابیس، Redis، broker یا اینترنت نیاز ندارند و با assertion رفتار مورد انتظار را بررسی می‌کنند؛ این نمونه‌ها ادعای تست یکپارچهٔ زیرساخت واقعی ندارند.

برای بررسی نوع‌ها، اجرای چهار مثال جدید یا همهٔ مثال‌های Node از فرمان‌های زیر استفاده کنید:

</div>

```bash
npm run typecheck
npm run interview-extra
npm run all-node
```

<div dir="rtl" style="text-align: right;">

`typecheck` همهٔ فایل‌های TypeScript این مجموعه را بدون تولید خروجی بررسی می‌کند. مثال‌های قدیمی Nest با transpile-only اجرا می‌شوند و اجرای آن‌ها به‌تنهایی صحت نوع‌ها را تأیید نمی‌کند؛ مثال‌های جدید 019 و 020 این گزینه را ندارند. `interview-extra` چهار مثال جدید را پشت سر هم اجرا و با اولین شکست متوقف می‌کند. `all-node` مثال‌های 001 تا 008 و 017 و 018 را اجرا می‌کند.

در تمرین، ابتدا پاسخ را بدون نگاه‌کردن توضیح دهید، سپس یک مثال شکست و دلیل انتخاب راه‌حل را بگویید و در پایان روش بررسی آن را مشخص کنید. منابع رسمی و ملاحظات نسخه در متن سؤال‌ها آمده‌اند.

**نکتهٔ اجرای مثال قدیمی 014:** transport داخلی TCP آن از پورت ثابت `127.0.0.1:43014` استفاده می‌کند. اگر سیستم این پورت را رزرو یا مسدود کرده باشد، اجرای آن با EACCES متوقف می‌شود؛ این خطا از محدودیت محیط است. مثال‌های جدید چنین پورت ثابتی ندارند.
